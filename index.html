Session display

Readouts on the Tracker page

How large the live figures on the Tracker page are drawn. The change applies as you drag, so flip to Tracker and check before you head out. Past about 120% on a phone the six tiles stack into one column and the Start/Stop buttons fall below the fold — readable from further away, but you have to scroll to reach them mid-run.

Pocket mode

While a run is tracking, the screen goes black after that long without a touch, so the phone can go in a pocket without setting off buttons — slide to unlock. The screen has to stay on for tracking to continue, so black is the cheapest thing to show: on an OLED panel black pixels are effectively off. Set the delay to 0 to only ever lock it by hand. A tap brings the readout back for a few seconds whatever the brightness, so 0% is usable.

Deezer playlist

The widget plays 30-second previews unless you are signed in to Deezer Premium inside it, and mobile browsers usually block autoplay — tap play manually.

Interval timer

End of work: 5 quick beeps. End of rest: 3 spaced, higher beeps. The series ends on a rising three-tone. They play on the media volume — turn it up before heading out, and test with the headphones you will actually wear.

Cadence

Steps per minute, read from the phone's motion sensor while the Tracker is in front. Check sensor measures what your phone actually delivers — the rate, and a live reading if you jog on the spot for a few seconds. It needs roughly 16 Hz to work and phones usually give 50–60; readings below 130 or above 220 spm are reported as nothing rather than guessed at. Samples stop when the app is not in front, so cadence pauses if you switch away.

GPS

Points reported with an accuracy worse than the threshold are ignored so a stationary phone does not inflate distance. Traces are decimated before being stored; the live session keeps full resolution in memory.

Location names

This is the app's only data request. When a run is saved, its start point — rounded to about 100 m — is sent to the French address base (api-adresse.data.gouv.fr), falling back to OpenStreetMap Nominatim outside France, and the answer is stored on the run so it is never asked again. Turn it off and nothing leaves the device. If you run with mobile data off, the lookup silently fails; Fill gaps resolves those runs later.

Backup

The export file is the only backup — data lives in this browser only. Import lets you merge (keep existing runs, add new ids) or replace everything.

Danger zone

Wake lock keeps the screen on during a session (Chrome on Android works best; iOS Safari support is inconsistent). No service worker, no offline install — everything already runs locally once the page is loaded.
